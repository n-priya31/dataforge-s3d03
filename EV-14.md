# EV-14 — HPA Auto-Scaling Verification

## Deliverable
D-07 — Horizontal Pod Autoscaling

## Verification
The DataForge worker HPA was verified in Minikube.

- Minimum replicas: 1
- Maximum replicas: 3
- CPU target: 50%
- During CPU load, utilization reached 81% and 88% of the target.
- HPA scaled the worker deployment to 3 replicas.
- `kubectl get pods -l app=dataforge-worker` confirmed 3/3 worker pods Running and Ready.
- CPU subsequently dropped to 14% and 0%.

## Verification Commands

```bash
kubectl get hpa dataforge-worker-hpa
kubectl get pods -l app=dataforge-worker

```
