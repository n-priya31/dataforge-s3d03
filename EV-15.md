# EV-15 — Gemini AI Anomaly Detection

## Deliverable
D-08 — Gemini AI Anomaly Detection

## Objective
Implement and verify an AI-based anomaly detection capability for the DataForge processing environment.

## Required Anomaly Scenarios

The AI capability is designed to detect the following three anomaly scenarios:

1. Memory leak / abnormal memory growth
2. Throughput degradation
3. Resource starvation

## Implementation

The anomaly detection module is implemented in:

`app/anomaly_detector.py`

The module:

- Uses the `google-genai` package.
- Reads the Gemini API key from the `GEMINI_API_KEY` environment variable.
- Uses the Gemini 2.5 Flash model.
- Sends processing metrics to Gemini for anomaly analysis.
- Requests an anomaly status, scenario, explanation, and resource optimization recommendation.

## Automated Verification

Tests are implemented in:

`tests/test_anomaly_detector.py`

The automated tests verify:

- All three required anomaly scenarios are defined.
- Memory leak / abnormal memory growth detection.
- Throughput degradation detection.
- Resource starvation detection.
- AI responses contain resource optimization recommendations.
